# Routine-Craft
Markdown # 🗓️ RoutineCraft - Haftalık Planlayıcı & A4 PDF Üretici  Haftalık beslenme, antrenman veya çalışma rutinlerinizi tarayıcı üzerinde oluşturabileceğiniz, `localStorage` ile veri kaybı olmadan saklayabileceğiniz ve tek tıkla **A4 Yatay (Landscape) PDF** formatında çıktı alabileceğiniz minimalist web uygulaması.  ![JavaScript](https://img.shields.io/badge/JavaScript-LocalStorage-F7DF1E?style=flat&logo=javascript&logoColor=black) ![CSS3](https://img.shields.io/badge/CSS3-Print_Media_Query-1572B6?style=flat&logo=css3&logoColor=white)  ## ✨ Öne Çıkan Özellikler - 💾 **Otomatik Kayıt (Auto-Save):** HTML5 `contenteditable` ve `localStorage` entegrasyonu ile her tuş vuruşu anında kaydedilir. - 🖨️ **Akıllı A4 Baskı Motoru:** Özel `@media print` kuralları sayesinde karanlık arayüz ve kontrol butonları gizlenerek mürekkep dostu bir A4 PDF çıktısı üretilir. - ⚡ **Hazır Şablon & JSON Dışa Aktarım:** Tek tıkla örnek program yükleme ve veriyi `.json` olarak yedekleme desteği.
